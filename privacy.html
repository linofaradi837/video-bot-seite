Privacy Policy

Last updated: November 2026

video-bot is a personal tool. It is operated by one person (the owner) for the owner's own use only. It is not offered to the public and has no other users.

What data the tool uses

  • Google account access: the owner signs in once with their own Google account and allows the permission youtube.upload. This permission is used only to upload videos to the owner's own YouTube channel.
  • Video content: the videos, titles and descriptions that the tool uploads are created by the owner. They contain no personal data of other people.
  • Authentication token: after sign-in, Google provides a token (refresh token) that lets the tool upload without signing in again.

What the tool does not do

  • It does not read, list, change or delete existing videos, comments, playlists or any other data on the YouTube account.
  • It does not collect data about viewers, visitors or any other person.
  • It does not use cookies, analytics or advertising on this website.

Storage

The authentication token is stored only on the owner's own computer and in private GitHub Secrets, which are encrypted and not visible to the public. It is not stored anywhere else and is not placed in any public repository or on this website.

Sharing

No data is sold, shared, transferred or disclosed to third parties. The only recipient is YouTube (Google), to which the owner's own videos are uploaded.

Google API Services

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

The owner can revoke the tool's access at any time at myaccount.google.com/permissions and delete the stored token from the computer and from GitHub Secrets.
